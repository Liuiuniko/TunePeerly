# TunePeerly 使用手册

TunePeerly（声渡）播放这台电脑上的音频文件，并分享给已配对的电脑。没有账号。本手册对应 0.6.0。

## 安装

运行 NSIS 安装程序。如果构建时生成了 MSI，也可以运行 MSI。NSIS 为当前 Windows 用户安装，不需要管理员权限。MSI 安装到 Program Files，安装时会要求管理员权限。

窗口需要 WebView2。Windows 11 通常已经自带。Windows 10 上如果缺少，并且当时可以上网，安装程序会下载它。

安装程序不添加防火墙规则。程序第一次开始监听其他设备时，Windows 防火墙可能会询问是否允许 `TunePeerly.exe`。在你使用的网络上允许它。放在另一个路径的程序会被当成另一个程序，需要再允许一次。在防火墙列表里搜索 `tunepeerly.exe`。

## 添加音乐

在设置的**曲库**里添加，或把文件夹和音频文件拖进窗口。程序在文件原来的位置读取，不复制，也不转码。

从曲库移除文件夹只是从 TunePeerly 里移除。磁盘上的文件还在。

**显示不可用的音乐**会把离线设备上的歌曲留在曲库和搜索结果里，这些行会变淡。

## 播放

底部播放条控制这台电脑自己的队列：播放、暂停、切歌、拖动进度、随机和重复。声音走系统默认输出设备。

在歌曲上右键可以**下一首播放**、**加入队列**、**加入歌单**和**收藏**。

队列只在这台电脑上，不会同步。

有 LRC 歌词时，点歌词按钮可以跟着歌曲滚动。播放条上的爱心把当前歌曲加入「喜欢的歌曲」。

## 窗口、托盘和迷你播放器

窗口使用自己的标题栏。设置 → 外观里的**关闭窗口时**决定关闭按钮的行为：

- **每次询问**会让你选择退出或收到托盘。
- **收到托盘**后播放继续。用托盘菜单重新显示窗口或退出。
- **退出**会结束程序。

**最小化时显示迷你播放器**会在屏幕上留下一条小播放条，上面有封面、播放控制和爱心。拖空白处可以移动。点封面或标题会打开主窗口。

Windows 任务栏缩略图上有上一首、播放、下一首和爱心。未喜欢时爱心是白色，已喜欢时是红色。

## 歌单和公开

歌单是歌曲列表。删除歌单不会删除歌曲。

设置 → 曲库里的**新的本机歌曲**决定一首不受歌单规则约束的歌是否提供给已配对设备。每个歌单可以跟随这个全局设置，也可以总是公开新加入的歌，或总是不公开。这个选择在歌曲加入时生效。**立即全部公开**和**停止全部公开**改的是已经在列表里的歌。

只有这台电脑正在公开一首歌时，已配对设备才能看到并播放它。还没有内容标识的歌曲留在本机。同步过来的歌单副本会把这些歌曲留在歌单最前面。

## 配对

打开**设备**。

- **发现附近设备**会每隔一会儿在局域网广播这台电脑的名字。广播里没有歌名。
- 也可以输入另一台电脑的地址和端口，或粘贴配对码。
- 两台电脑都接受之后，配对才完成。在那之前连接处于等待确认。
- 拒绝一次请求后，对方要等**拒绝后的静默时间**过去才能再请求。默认是 60 秒。你仍然可以主动连接那台设备。
- 拉黑会移除一台设备，之后来自它的数据会被丢弃。

不在同一局域网时，把设置 → 网络里的四项中继信息都填上。中继只在你的设备之间转发。设备之间会加密，中继读不到内容。

**局域网端口**会保存并在下次启动时继续使用，范围是 1024–65535。启动时如果这个端口被占用，程序会临时改听另一个端口并显示警告。保存的端口不会被改掉。

## 播放另一台电脑上的歌

在线的已配对设备公开的歌，可以从那台设备播放。播放条会显示那台设备的名字。**下载**把原始文件存进下载文件夹，并加入这台电脑的曲库。下载文件夹在第一次下载时选择。

## 同步

无痕模式会关掉同步。使用这一节之前先关掉无痕模式。

喜欢的歌曲、歌单和外观各自按一整份副本同步。副本是当时的完整内容，不是一条条修改记录。

| 控制 | 作用 |
| --- | --- |
| 自动发送 | 勾选的项目在这台电脑上改动后，把这份副本发给所有在线的已配对设备。 |
| 跟随 | 所选设备改了这项之后，自动采用它的副本。 |
| 发送 | 立刻把这台电脑的副本推给所有在线的已配对设备。 |
| 覆盖 | 向一台在线设备要它的副本，并替换这台电脑上的副本。 |
| 屏蔽手动 | 这台电脑不发送，也不回应别的设备发来的覆盖请求。 |
| 屏蔽跟随 | 忽略自动发来的副本。 |
| 全部屏蔽 | 不发送，也不跟随。 |

覆盖不受两边的**屏蔽手动**、**屏蔽跟随**和**全部屏蔽**影响。无痕模式仍然会拦住它。收到的是对方当时的整份内容。

**他人覆盖本机时**作用于对方按下发送。**静默**会立刻替换。**先询问**会等你确认。覆盖不再询问，因为这份副本是你主动要的。

**同步发生冲突时**用于你正在跟随一台设备，而这台电脑也有还没发出去的修改。可以保留本机、采用对方，或每次询问。

外观同步包括主题、语言、迷你播放器开关，以及关闭窗口时的选择。

歌单副本会替换整组歌单。副本里没有的歌单会被删除。名称和顺序按副本来。还没有内容标识的歌曲留在所属歌单的最前面。歌单自己的公开或隐藏选择留在这台电脑上。

## 最近播放

一首歌播完才记下来。**暂停记录**或无痕模式打开时不记。**最近播放保留的歌曲数**是列表长度上限，范围是 1 到 10000。

**同步最近播放**把这份列表发给在线的已配对设备。对方只有自己也打开这个开关才会合并。两份列表按每首歌最新的 UTC 时间合并。时间相同就保留一条。

**这台电脑上线时合并**会向每台已配对设备要列表，合并收到的回复，再把结果发出去。没有打开历史同步的设备会忽略这个请求。

## 跟随播放

在设置 → 网络里，**跟随播放**列出当前在线的已配对设备。选一台。

底部播放条随后显示那台设备正在听的歌。对方播放时进度条前进，对方暂停时进度条停下。播放按钮保持为播放。这台电脑不发声，这条播放条上的播放按钮也不会在这里开始播放。

选**不跟随**后，恢复使用这台电脑自己的播放器。

两台电脑都要使用带有这个功能的版本。被跟随的电脑在载入歌曲后，大约每秒发送一次进度。无痕模式会停止这个交换。

## 通知

铃铛打开通知列表。可以在通知滚进视野时标为已读，在打开面板时标为已读，或只在你点开一条时标为已读。清除时可以每次询问，删除未固定的通知，或全部删除。

## 数据留在哪里

`%AppData%\Roaming\TunePeerly\library.db` 保存曲库、歌单、收藏、最近播放、配对和设置。卸载程序不会删除这个文件夹。

没有账号。离开局域网后，同步和串流经过你配置的中继。中继转发加密流量，读不到内容。
